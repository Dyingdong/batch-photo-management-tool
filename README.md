# 批量管理照片软件

原生 macOS 图形界面软件，用于批量整理相机 RAW 与 JPG 照片。由仓库中三个 Python 命令行脚本整合升级而来。

当前版本：**v1.0**（Apple Silicon / arm64）。

## 快速开始

1. 从本仓库 [Releases](../../releases) 下载 `BatchPhotoManager-v1.0-arm64.zip`（解压后即「批量管理照片软件.app」）；
2. 解压得到 `批量管理照片软件.app`，拖进「应用程序」或直接双击运行；
3. 若首次打开被系统拦截（提示"无法验证开发者"或"已损坏"），在终端执行 once：
   ```bash
   xattr -cr /路径/批量管理照片软件.app
   ```
   再双击打开即可（软件为本地 ad-hoc 签名，未做 Apple 公证）；
4. 打开后把照片文件夹直接拖进窗口，或按 ⌘O 选择文件夹，软件会自动递归扫描。

**系统要求**：macOS 13.0 及以上，Apple Silicon（arm64）芯片。**仅支持 RAW/JPG 文件的整理与归集，不修改照片内容。**

## 一、原仓库代码梳理

仓库 `batch-photo-management-tool` 原先是三个互相重叠的命令行脚本，功能重复、入口分散（原始脚本已归档到 [`历史文件/`](历史文件/) 目录保留）：

| 脚本 | 处理格式 | 功能 | 撤销 |
|------|----------|------|------|
| `photo_workflow.py` | 仅 Canon CR3 | 6 项：移出无匹配 CR3、汇总全部 CR3、移出有匹配 CR3（当前/递归）、归集 JPG（当前/递归） | 支持 |
| `photo_workflow1.py` | 全品牌 RAW | 6 项：移出无匹配 RAW、复制全部 RAW、移出有匹配 RAW（当前/递归）、归集 JPG（当前/递归） | 支持 |
| `摄影小工具.py` | CR3/DNG | 3 项：移出无匹配 RAW、复制全部 RAW、复制有匹配 RAW | 不支持 |
| `move_unused_raw.py` | CR3/DNG | 1 项：递归移出无匹配 RAW | 不支持 |

**核心逻辑（三套脚本共通）**：
- 按「主文件名相同（不区分大小写）」判定 RAW 与 JPG 配对；
- 递归遍历文件夹，自动跳过隐藏目录和工具自己生成的目录；
- 把文件移动/复制到指定中文子目录，重名时自动加 `_1`、`_2` 后缀，不覆盖；
- 用 `操作日志.jsonl` 记录每一步（事务 ID + 动作 + 源/目标），支持撤销最近一次操作。

**原脚本的痛点**：需要记数字命令、看终端输出、拖文件夹进终端、无法直观看到将影响哪些文件。

## 二、本软件做了什么

把上述逻辑整合为一个原生 SwiftUI App，图形化呈现：

- **目录选择**：系统文件夹选择器，选择后自动递归扫描；
- **概览统计**：文件夹数 / RAW 数 / JPG 数 / 有匹配 / 无匹配，一目了然；
- **拖拽文件夹**：直接把文件夹拖进窗口即可设为根目录，也可点击「选择文件夹」（⌘O）；
- **8 个整理任务**（按 RAW、JPG、清理分组）：
  1. 移出无同名 JPG 的 RAW（逐文件夹，放入各自的「无同名JPG的RAW」）
  2. 汇总全部 RAW（复制，放入根目录「全部RAW」，原文件保留）
  3. 移出当前目录有同名 JPG 的 RAW
  4. 移出所有目录有同名 JPG 的 RAW
  5. 归集当前目录 JPG
  6. 归集所有目录 JPG
  7. **删除无同名 JPG 的 RAW**（移到系统废纸篓）
  8. **删除无同名 RAW 的 JPG**（移到系统废纸篓）
- **执行前预览**：显示每个任务将处理的文件数量、涉及文件夹、目标位置和前 10 个文件清单，确认后才执行；删除任务用红色标识并二次确认；
- **事务与撤销**：所有操作写入 `操作日志.jsonl`，顶部栏、状态栏、左侧操作记录均可撤销最近一次（⌘Z）。删除的文件撤销时会从废纸篓搬回原位置；
- **安全设计**：删除是「移到废纸篓」而非永久删除（可从废纸篓找回）、同名不覆盖（自动编号）、跳过工具生成目录避免重复整理、复制模式保留原文件。

## 三、目录与构建

```
.
├── App/
│   ├── App.swift              # SwiftUI 界面（含企业级设计令牌）
│   └── Info.plist             # Bundle 配置（local.workbuddy.batchphotomanager）
├── Sources/
│   └── PhotoCore.swift        # 核心逻辑：扫描/匹配/整理/事务/撤销
├── Tests/
│   └── coretest/main.swift    # 核心逻辑自动化测试
├── 历史文件/                   # 原仓库 Python 脚本归档
├── build.sh                   # 编译打包脚本
└── 批量管理照片软件.app        # 构建产物（由 build.sh 生成，不入库）
```

构建（需要 Apple Silicon + Swift 5）：

```bash
bash build.sh
```

脚本会用 `swiftc` 直接编译 SwiftUI App，做 ad-hoc 签名（固定 identifier，保证文件夹授权在重编译后仍有效），产物为 `批量管理照片软件.app`。

## 四、验证情况

核心逻辑自动化测试 32 项全部通过，覆盖：递归扫描、大小写不敏感匹配、无匹配/有匹配分类、无同名 RAW 的 JPG 识别、移动、复制保留原文件、跳过生成目录、事务撤销与同名恢复、删除到废纸篓、从废纸篓撤销还原。

## 五、匹配规则说明

- RAW 支持：CR2/CR3、NEF/NRW、ARW/SRF/SR2、RAF、ORF、RW2、PEF、SRW、DNG、RAW；
- JPG 支持：JPG、JPEG；
- 配对规则：去掉扩展名、去除首尾空格、不区分大小写后相同即视为一对（如 `IMG_001.CR3` 与 `img_001.jpg` 配对）。
